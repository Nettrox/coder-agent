Changed

* Migrated from monolithic prompts to modular Prompt Builder architecture.
* Introduced Context Builder as the primary reasoning layer before code generation.
* Standardized documentation across the entire project.
* Established architecture decision recording (ADR) process.

⸻

Known Limitations

* Writer Engine is not yet implemented.
* Generated changes are not automatically applied to projects.
* Backup and rollback mechanisms are planned for the next milestone.
* Semantic retrieval and long-term memory are not yet available.
